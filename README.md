# Hackathon Projects

This repository groups two independently maintained projects as Git submodules:

- `jharkhand-tourism` — First Hackathon Project
- `johar-jharkhand-tourism` — Second Hackathon Project

Clone this repository and its projects with:

```sh
git clone --recurse-submodules https://github.com/akshatupadhyay-01/Hackathon.git
```

If you already cloned the repository without submodules, run:

```sh
git submodule update --init --recursive
```
